# 🎵 NeoBeats - Premium Music Player

A modern and responsive music player built using HTML, CSS, and JavaScript. NeoBeats provides a clean user interface with smooth animations and interactive music playback features.

## ✨ Features

- 🎵 Play, Pause, Next & Previous controls
- 🔀 Shuffle & Repeat mode
- ❤️ Add songs to Favorites
- 🔍 Search songs instantly
- 📜 Recently Played section
- 🌙 Dark / Light Theme
- 🔊 Volume Control
- 📥 Download Current Song
- 📱 Responsive Design
- 💾 Local Storage Support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
NeoBeats-Music-Player/
│── assets/
│── songs/
│── index.html
│── style.css
│── script.js
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Install the Live Server extension.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
